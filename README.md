# ApexPlanet Internship — Task 4

This project contains a multi-page portfolio website, a persistent to-do list with localStorage, and a product listing page with filtering and sorting.

## Project structure

```text

│   ├── todo.js

```

## Run locally

1. Open the folder in a browser, or run a local server from the project root:
   ```bash
   cd "c:\Users\anirm\OneDrive\Desktop\Programming\ApexPlanet\Task-4"
   python -m http.server 8000
   ```
2. Visit: http://localhost:8000

## Features included

- Personal portfolio with Home, About, Projects, and Contact pages
- Responsive navigation and mobile-friendly layout
- Contact form validation with required fields and email validation
- To-do list with add, delete, complete, and localStorage persistence
- Product page with category filtering, price filtering, dynamic sorting, and DOM-rendered cards
- Design system using CSS variables and responsive layout rules
